# Starlight

Système d'éclairage pilotable : chaque source lumineuse est une « étoile », pilotable seule, par secteur ou toutes ensemble, en mode **Lounge** (ambiances) ou **Stream** (réactions aux événements Twitch).

🚧 **Projet en cours de refonte.** La première version (preuve de faisabilité) est archivée dans [`archive/v0/`](archive/v0/README.md).
