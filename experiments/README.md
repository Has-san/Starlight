# Expériences

Essais ponctuels pour lever un doute technique, **hors du code de production**.
Un dossier par expérience (`EXP-01/`), avec une fiche `README.md` (objectif, protocole, résultat, conclusion) et les scripts utilisés.
Le code d'une expérience n'est pas maintenu : ce qui doit durer est réécrit proprement dans `host/` ou `firmware/`.
