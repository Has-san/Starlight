# simulator — étoiles simulées

Remplace le matériel pour développer et tester le logiciel hôte (`host/`) sans rubans de LED ni ampoules : utile aux contributeurs sans matériel, aux tests d'intégration et aux agents.

Le simulateur joue le rôle du pilote : il annonce des étoiles et respecte le même contrat de communication que le firmware.
